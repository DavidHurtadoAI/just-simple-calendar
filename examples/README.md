# Try the demo

1. Create a folder named `Simple Calendar Demo` at the root of a test vault.
2. Copy `Studio Calendar.base` and the `Notes` folder into it.
3. Enable Bases and Just Simple Calendar, then open `Studio Calendar.base`.
4. Navigate to **September 2026** to see the example events.

The examples are fictional and editable. They use `start_date`, optional `end_date`, and `focus` properties. Hover previews use Obsidian's built-in Page preview feature.
